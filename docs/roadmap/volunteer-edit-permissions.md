# Secure activity editing

## Goal
Implement an Edit listing button for assigned leaders, admins and authorised volunteers. Reuse existing editor, enforce server-side listing/region scope, support immediate publishing, and record audit history. Do not grant permissions from client input.

## Acceptance criteria
- Existing accounts and listings are preserved.
- Access checks are performed on the server.
- Mobile-friendly styling follows Bubba Hub.
- Test on staging before live deployment.

Status: implementation planned; no production functionality added by this planning PR.
