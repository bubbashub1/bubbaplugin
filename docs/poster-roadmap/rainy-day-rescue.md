# Rainy Day Rescue

Planning only; no executable code.

## Scope
Indoor activities and family facilities with source-verified details.

## Implementation checklist
- Inventory existing PHP APIs, routes and bh_* tables; reuse canonical records.
- Define mobile UI, admin moderation, ownership and Free/Pro permissions.
- Specify validation, accessibility, privacy, migrations and rollback.
- Test empty states, filtering, invalid data, duplicates, mobile and permissions on staging.
- Explicit approval required before merge/deploy.

Birthday Party Finder and party spaces are excluded.
